# Калькулятор с поддержкой плагинов

Интерактивный калькулятор на C++, который поддерживает базовые операции и легко расширяется через систему плагинов.

## Особенности

- ✅ **Поддержка стандартных операций**: сложение, вычитание, умножение, деление
- ✅ **Встроенные математические функции**: sin, cos, ln, pow
- ✅ **Система плагинов**: легко добавляйте новые функции без перекомпиляции основного приложения
- ✅ **Корректная обработка приоритета операций**: использует алгоритм обратной польской нотации (RPN)
- ✅ **Поддержка скобок**: правильное вычисление выражений со скобками

## Структура проекта

```
calculator/
├── main.cpp                    # Точка входа приложения
├── calculator.hpp/cpp          # Главный класс калькулятора
├── parser.hpp/cpp              # Парсер выражений (токенизация → RPN)
├── evaluator.hpp/cpp           # Вычислитель (обработка токенов в RPN)
├── functionRegistry.hpp/cpp    # Реестр функций и загрузчик плагинов
├── baseClasses.hpp             # Базовые структуры (Token и т.д.)
├── IPluginFunction.hpp         # Интерфейс для плагинов
├── CMakeLists.txt              # Конфигурация сборки
├── operations/                 # Встроенные операции
│   ├── add.cpp, sub.cpp        # Сложение, вычитание
│   ├── mult.cpp, divide.cpp    # Умножение, деление
│   ├── sin.cpp, cos.cpp        # Тригонометрические функции
│   ├── ln.cpp, pow.cpp         # Логарифм и степень
└── plugins/                    # Скомпилированные плагины
```

## Компиляция

### Требования
- C++17 или выше
- CMake 3.10+
- GCC/Clang (Linux) или MSVC (Windows)

### Сборка

```bash
cd calculator
mkdir -p build && cd build
cmake ..
make
```

Исполняемый файл будет в `build/bin/calculator`

## Использование

```bash
./calculator
```

Введите математическое выражение и нажмите Enter. Примеры:

```
2 + 3 * 4           # Результат: 14
sin(0.5) + cos(0)   # Результат: 1.479...
2^3 - ln(1)   # Результат: 8
(10 + 5) / 3        # Результат: 5
```

Для выхода введите `exit` или `quit`.

## Архитектура

### Парсер (Parser)
- Токенизирует входное выражение
- Преобразует инфиксную нотацию в обратную польскую нотацию (RPN)
- Обрабатывает приоритет операций и скобки

### Вычислитель (Evaluator)
- Обрабатывает последовательность токенов в RPN
- Использует стек для вычисления результата

### Реестр функций (FunctionRegistry)
- Управляет доступными функциями
- Автоматически загружает плагины из директории `plugins/`
- Поддерживает динамическую загрузку функций

## Система плагинов

Для добавления новой функции создайте файл плагина:

```cpp
#include "IPluginFunction.hpp"

extern "C" {
    double execute(double const* args, int argCount) {
        if (argCount != 1) return 0;
        return args[0] * 2; // Ваша реализация
    }
    
    int getArity() { return 1; }
    
    const char* getName() { return "double"; }
    
    void registerPluginFunctions() {
        // Регистрация в системе
    }
}
```

Скомпилируйте как динамическую библиотеку и поместите в папку `build/plugins/`, при этом перекомпилировать проект не нужно.
